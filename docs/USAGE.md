# 使用指南

[返回项目首页](../README.md)

## 每天如何使用

1. 打开 **Study Desk**，查看日期、本周论文与今日学习重点。
2. 从阅读卡或 **Learning Queue** 进入阅读、词汇和口语详情。
3. 在 **Today's Tasks** 勾选完成，或到 **Plans** 添加个人任务、从任务池复制模板、拖动调整顺序。
4. 需要保存材料时，在学习详情使用 **Save to Notion**；首次使用先到 **Settings** 配置集成。
5. 在 **Settings → Activity History** 查看任务完成情况与活动热力图。

日期和每日内容的选取使用 **Asia/Shanghai** 时区。

## 学习内容

### Speaking Practice

内置七类场景：课堂、健身房、食堂、宿舍、班级活动、企业参访和娱乐。对话详情提供中英对照、常用表达、语气说明和练习提示。

配置 DeepSeek 后，当天首次生成对话时会尝试调用 AI；已有的当天对话会复用，修改密钥不会立即重生成。未配置或调用失败时使用对应的内置场景。

### Reading 与 Vocabulary

内置六条论文学习材料，按周轮换；词汇与阅读共同使用本周材料。内容带论文标题、作者、期刊、年份和 DOI，属于学习库材料，引用前需沿 DOI 核对原文。

| 日期 | 当前学习安排 |
| --- | --- |
| 周一至周三 | 分段阅读与分组词汇；周三在对应片段可用时加入写作重点 |
| 周四 | 阅读延续日；当前配置未分配常规词汇组，阅读片段可能为空 |
| 周五 | 完整词汇复习 |
| 周六 | 讨论问题与完整词汇 |
| 周日 | 本周材料整体复习：阅读、写作重点、词汇与讨论 |

**Reading History** 只展示本周已生成的记录。论文条目按基础标题去重；未访问的日期不会由定时任务自动补齐。

## 任务与连续活跃天数

- 在当天还没有任务和学习内容时，首页或 Learn 的首次内容初始化会创建三项学习任务。
- 已经手动添加任务，或当天内容已经存在时，不保证再次补齐三项默认任务；删除后的任务不会在刷新时自动恢复。
- **Task Pool** 是可复用的任务模板；点击复制后进入当天任务。
- 每天至少完成一项任务，才会更新连续活跃天数；它不要求当天所有任务都完成。完成当天最后一项未完成任务时会出现动画反馈。
- 首页支持勾选与排序，Plans 提供任务添加、删除和模板管理。

## Notion 的行为

学习材料支持手动保存，也会在启用配置后随页面访问尝试自动推送；本地的 `pushed` 标记用于跳过已经保存的材料。自动推送失败不会阻止页面使用，但页面打开成功不代表 Notion 已保存成功。

任务创建与完成状态切换会向 Notion 追加新页面。当前不更新既有 Notion 任务，也没有双向同步，所以同一任务可能在 Notion 留下多条状态记录。字段和配置见 [集成配置](INTEGRATIONS.md)。
